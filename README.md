# Sistema de Casa de Leilões

## Sobre o Projeto
Sistema informatizado para automatizar as operações de uma casa de leilões. Permite o gerenciamento completo de itens, lances, usuários e processos de leilão, oferecendo uma solução robusta e eficiente para o ambiente de leilões.

## Tecnologias Utilizadas
- **Java** - Linguagemo principal
- **MySQL** - Sistema de banco de dados

## Funcionalidades
- Cadastro e gerenciamento de itens para leilão
- Controle de usuários e sistema de autenticação
- Registro e acompanhamento de lances em tempo real
- Gestão de leilões ativos e finalizados
- Relatórios e histórico de transações
- Interface para acompanhamento de lances

## Como Executar
1. Importe o banco de dados MySQL fornecido no projeto
2. Configure as credenciais de acesso ao banco no arquivo de configuração
3. Execute a aplicação Java principal
4. Acesse o sistema através da interface definida

## Pré-requisitos
- Java JDK 8 ou superior
- MySQL Server 5.7 ou superior
- Conexão com banco de dados configurada

## Versionamento
O projeto utiliza Git para controle de versionamento e GitHub como repositório remoto.
